# Joint Model NLME-SAEM for Pregnancy Outcomes

This repository contains the code, simulated data, and reproducible materials associated with a joint modeling approach combining nonlinear mixed-effects models (NLME) and the SAEM algorithm for the analysis and prediction of pregnancy outcomes.

## Repository structure

The repository will contain:

- R code for model implementation and estimation.
- Simulated data for reproducibility.
- Scripts used to reproduce the analyses.
- Figures and results generated from the analyses.
- Documentation describing the methodology and use of the code.

## Data availability

The original clinical data are not publicly available due to confidentiality restrictions. A synthetic dataset with similar characteristics is provided for reproducibility and demonstration purposes.
